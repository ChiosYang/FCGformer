# 数据集介绍 (Datasets)

本目录下存放了用于长序列时间序列预测（主要针对空气质量与气象数据）的各项数据集。

## 1. Center.csv (华中地区数据集)
- **文件大小**：约 168 MB
- **数据描述**：收集自华中地区的空气质量与气象历史数据。
- **特征维度**：包含 `date` (时间戳), `location` (站点/位置ID), 以及多种空气污染物指标（如 `AQI`, `CO`, `NO2`, `O3`, `PM10`, `PM2.5`, `SO2` 及其 24 小时或 8 小时均值等）和气象指标（如 `Air Temperature`, `Dew Point Temperature`, `Wind Direction`, `Wind Speed Rate`, `ELEV(M)`）。
- **预测目标 (Target)**：列名为 `OT`，通常作为模型的预测目标变量（Target）。

## 2. EastNorth.csv (东北地区数据集)
- **文件大小**：约 173 MB
- **数据描述**：收集自东北地区的空气质量与气象历史数据。
- **特征维度**：与 `Center.csv` 的字段基本相同，同样包含了多维度的污染物浓度及气象特征。
- **数据结构差异**：需要注意的是，在 `EastNorth.csv` 中，目标列 `OT` 位于第 17 列（污染特征和气象特征之间），而在 `Center.csv` 中 `OT` 位于最后一列。某些情况下需注意列索引的区别。

## 3. Test.csv (测试采样数据集)
- **文件大小**：约 1.8 MB
- **数据描述**：这是从 `EastNorth.csv` 中截取的一个微型采样版本（列结构与 `EastNorth.csv` 完全一致）。
- **使用场景**：主要用于代码开发阶段的快速调试 (Debug) 或流水线跑通测试。当您需要验证网络结构修改是否能正常 Work 时，使用该数据集可以大幅减少数据加载时间和显存/内存消耗。

---

## 核心字段说明参考

| 字段名称 | 描述说明 |
| :--- | :--- |
| `date` | 记录时间，通常为小时级分辨率 (例如 `2022-01-01 00:00:00`) |
| `location` | 监测站点的数字化标识 ID |
| `AQI`, `PM2.5`, `PM10`... | 各类空气质量指数和污染物浓度（包含单小时与 24h/8h 滑动平均值） |
| `Air Temperature` | 空气温度 |
| `Dew Point Temperature` | 露点温度 |
| `Wind Direction` / `Wind Speed Rate` | 风向与风速 |
| `ELEV(M)` | 监测站所在海拔高度（米） |
| `OT` | 核心预测目标变量 (Objective Target) |

> **💡 使用提示**：
> 在通过执行脚本（如 `run.py`）使用这些数据集时，请确保配置了以下参数：
> - `--data custom` (表示自定义 CSV)
> - `--root_path ./dataset/`
> - `--data_path Center.csv` 或其他文件名
> - 正确配置 `--enc_in`, `--dec_in`, `--c_out` 参数以匹配数据集的实际特征数量（去掉 date 列后的列数）。
